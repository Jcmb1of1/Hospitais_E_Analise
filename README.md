# Hospitais e Análise

## Fonte dos dados
- Dataset analisado: https://dados.gov.br/dados/conjuntos-dados/hospitais-e-leitos
- Fonte: Portal de Dados Abertos
- Dados utilizados para fins de estudo e análise com Python e Pandas.
- Licença: Creative Commons Attribution (CC BY)


## Tecnologias 
- Python
- Pandas
- Matplotlib

## Funcionalidades
- mostrar_estabelecimentos - Mostra os estabelecimentos de saúde de determinado estado, junto às suas informações.
- estabelecimentos_por_estado - Apresenta um gráfico de estabelecimentos de saúde por estado.

## Como executar na sua máquina.
1 - Clone o repositório 
2 - Instale as bibliotecas pandas e matplotlib
3 - Utilize os métodos da área "Funcionalidades".
4 - Execute o projeto!
